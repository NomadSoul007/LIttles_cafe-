# Настройка Meta Pixel и Google Sheets

## 1. Meta Pixel

1. Откройте Meta Events Manager и скопируйте числовой ID нужного Pixel.
2. Откройте файл `meta-pixel.js`.
3. Замените `PASTE_META_PIXEL_ID_HERE` на ID без пробелов и дополнительных символов.
4. Повторно опубликуйте сайт на Vercel.
5. Проверьте событие `PageView` через Test Events или Meta Pixel Helper.
6. На странице `/reservation` отправьте тестовую заявку. После подтверждённой записи в таблицу должно появиться событие `Lead`.

Если ID не подставлен или имеет неверный формат, Pixel не загружается и не создаёт ошибок в консоли.

## 2. Google Sheets

1. Создайте новую Google-таблицу.
2. В таблице откройте **Расширения → Apps Script**. Важно создавать скрипт именно из таблицы, чтобы он был к ней привязан.
3. Удалите исходный код редактора и вставьте содержимое файла `google-apps-script/Code.gs`.
4. Сохраните проект.
5. Нажмите **Развернуть → Новое развертывание**.
6. Выберите тип **Веб-приложение**.
7. В поле выполнения выберите **От моего имени**.
8. В доступе выберите **Все**. Если Google показывает вариант **Все, у кого есть аккаунт Google**, он не подходит для публичной формы.
9. Подтвердите разрешения и нажмите **Развернуть**.
10. Скопируйте URL веб-приложения. Он должен оканчиваться на `/exec`.

Скрипт сам создаст лист `Заявки`, если его ещё нет, и подготовит столбцы:

| Дата | Имя | Телефон | Количество персон |
| --- | --- | --- | --- |

Чтобы дата отображалась по времени Алматы, в Apps Script откройте **Настройки проекта** и установите часовой пояс `Asia/Almaty`. Такой же часовой пояс желательно выбрать в настройках Google Sheets.

## 3. URL Apps Script в Vercel

URL не хранится в клиентском JavaScript.

1. Откройте проект в Vercel.
2. Перейдите в **Settings → Environment Variables**.
3. Создайте переменную:
   - Name: `GOOGLE_APPS_SCRIPT_URL`
   - Value: URL веб-приложения Google Apps Script, оканчивающийся на `/exec`
4. Включите переменную как минимум для `Production` (при необходимости также для `Preview`).
5. Выполните новый deployment.

При последующих изменениях кода Apps Script создавайте новую версию развертывания через **Управление развертываниями → Изменить → Новая версия**. URL при этом можно сохранить прежним.

## 4. Проверка

1. Откройте `/reservation`.
2. Нажмите любую кнопку бронирования или WhatsApp — должна открыться форма без перехода в WhatsApp.
3. Отправьте тестовые данные.
4. Убедитесь, что в листе `Заявки` появилась ровно одна новая строка.
5. Убедитесь, что появилось сообщение об успехе, форма очистилась и закрылась автоматически.
6. Проверьте `Lead` в Meta Test Events.
7. Временно укажите неверный URL Apps Script в Preview-окружении и убедитесь, что пользователь видит сообщение об ошибке, а `Lead` не отправляется.
