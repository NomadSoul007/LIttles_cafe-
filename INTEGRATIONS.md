# Настройка Meta Pixel и Google Sheets

## Meta Pixel

1. Откройте `meta-pixel.js`.
2. Замените `PASTE_META_PIXEL_ID_HERE` на реальный числовой Pixel ID.
3. Опубликуйте новый deployment сайта.
4. Проверьте `PageView` через Meta Test Events или Meta Pixel Helper.

Если ID не подставлен или имеет неверный формат, Pixel не загружается и не
создаёт ошибок в консоли.

Событие `Lead` отправляется только после успешного ответа
`/api/reservations`, подтверждающего запись в Google Sheets.

## Google Sheets

Скрипт работает с таблицей:

```text
1GqeSzHeC03aH9-maK2tb6g_NzcnCAfGHnuK3fYLWPT8
```

Лист `Заявки` использует столбцы:

```text
№
Дата и время
Имя
Телефон
Количество гостей
```

`setupSheet()` автоматически:

- создаёт лист `Заявки`, если его нет;
- мигрирует прежнюю четырёхколоночную структуру;
- восстанавливает заголовки;
- нумерует существующие заявки;
- устанавливает часовой пояс `Asia/Almaty`;
- оформляет заголовок;
- закрепляет первую строку;
- добавляет фильтр;
- задаёт ширину столбцов и форматы данных.

### Установка Google Apps Script

1. Откройте нужную Google-таблицу.
2. Выберите **Расширения → Apps Script**.
3. Замените содержимое редактора кодом из `google-apps-script/Code.gs`.
4. Сохраните проект.
5. Откройте **Настройки проекта → Свойства скрипта**.
6. Добавьте свойство:

   ```text
   RESERVATION_SECRET
   ```

7. В качестве значения укажите случайный секрет длиной не менее 32 символов.
8. В редакторе Apps Script один раз вручную запустите `setupSheet()` и
   подтвердите запрошенные разрешения.
9. Убедитесь, что лист `Заявки` оформлен и содержит пять указанных столбцов.

Секрет нельзя вставлять в `Code.gs`, клиентский JavaScript или HTML.

### Публикация как Web App

1. Нажмите **Развернуть → Новое развертывание**.
2. Выберите тип **Веб-приложение**.
3. В поле выполнения выберите **От моего имени**.
4. В доступе выберите **Все**.
5. Подтвердите разрешения и нажмите **Развернуть**.
6. Скопируйте URL, который оканчивается на `/exec`.

После последующих изменений Apps Script откройте
**Управление развертываниями → Изменить**, выберите **Новая версия** и
обновите существующий deployment. Его URL `/exec` при этом останется прежним.

## Vercel Environment Variables

В **Settings → Environment Variables** создайте:

```text
GOOGLE_APPS_SCRIPT_URL
GOOGLE_APPS_SCRIPT_SECRET
```

- `GOOGLE_APPS_SCRIPT_URL` — HTTPS-адрес Web App, оканчивающийся на `/exec`.
- `GOOGLE_APPS_SCRIPT_SECRET` — то же значение, которое сохранено в
  Script Properties как `RESERVATION_SECRET`.

Обе переменные должны быть включены для `Production`. После добавления или
изменения переменных обязательно выполните новый deployment Vercel.

## Маршруты

```text
/
/add
/reservation → /add
```

- `/` показывает основной сайт; форма открывается только кнопкой.
- `/add` показывает тот же сайт; форма открывается только кнопкой.
- `/reservation` и `/reservation/` постоянно перенаправляются на `/add`.
- Все элементы с `data-reservation-trigger` открывают модальное окно.

## Финальная проверка

1. Откройте `/` и убедитесь, что при загрузке страницы форма закрыта, а после
   нажатия кнопки бронирования открывается.
2. Закройте форму и повторно откройте её кнопкой бронирования.
3. Откройте `/add` и убедитесь, что форма закрыта до нажатия кнопки
   бронирования.
4. Откройте `/reservation` и проверьте redirect на `/add`.
5. Проверьте, что верхняя и плавающая кнопки WhatsApp по-прежнему открывают
   выбор филиала и WhatsApp.
6. Отправьте по одной корректной заявке с `/` и `/add`.
7. Убедитесь, что каждая отправка создала ровно одну строку.
8. Проверьте номер заявки, дату, телефон со знаком `+` и количество гостей.
9. Отправьте запрос без секрета и убедитесь, что строка не добавилась.
10. Проверьте отклонение неверного телефона, `0` и значения больше `100`.
11. Проверьте `Lead` в Meta Test Events после успешной записи.
12. Временно вызовите ошибку интеграции в Preview-окружении и убедитесь, что
    пользователь видит сообщение об ошибке, а `Lead` не отправляется.
